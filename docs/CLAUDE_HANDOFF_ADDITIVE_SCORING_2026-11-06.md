# 보고서 합산 점수 복원과 세부 지표 확장

운영 상태: 2026-11-06 21:00 KST에 실제 점수·가격 재산정을 완료했다. 개인·팀원 저장소 main 병합과 두 Vercel 운영 배포를 확인했다. 이후의 실제 데이터·공간·권한 검증도 통과했다.

## 확정 정책

사용자는 10점 상한과 기본 6점을 거부했다. 원래 보고서의 배점(출전 2/1, 골 GK10/DF6/MF5/FW4, 도움 GK5/DF4/MF3/FW3 등)을 복원한다. 원점수는 항목 합계 그대로 보존하고 상·하한을 두지 않는다. 20~30점 이상과 음수도 가능하다.

추가 승인 배점: 패스 성공 10회당 +0.5, 볼 회수 +0.5, 클리어런스 +0.25, 드리블 성공 +0.5, 슈팅 차단 +0.5, 피파울 +0.25, GK 공중볼 처리·스위퍼 성공 각각 +0.5. 성공 카운터만 사용한다. 전체 경합 수·터치·API 평점을 또 더하지 않는다. 누락/비정상 카운터는 임의로 채우지 않는다.

초기 가격은 기존의 확정된 이전 시즌 포지션별 백분위 50,000~150,000P를 유지한다. 운영 시작은 2026-10-15 00:00 KST다. 이후 종료된 5대 정규 리그 경기만 가격 변동으로 발행한다. 이전 자료는 고정 기준을 만드는 데만 사용한다.

가격 비교 기준은 운영 시작 전에 종료된 유효 출전의 포지션별 합산 점수 평균이다. 신규 지표를 포함한 같은 배점을 사용하고 표본 수를 기록한다. 운영 시작 이후의 경기는 기준에 섞지 않는다. 기준은 한 번 정한 뒤 동결한다.

제한 전 증감 포인트 = 100,000P × (이번 경기 점수 − 포지션 기준) / max(|포지션 기준|, 1) × 0.10 × min(출전 분 / 60, 1).
증감 포인트를 직전 가격에 더한다. 경기당 ±10%와 최소 10,000P를 적용하고 정수 반올림 후 한도를 다시 확인한다. 고정된 100만P 게임 상한은 제거했다. MAX_SAFE_INTEGER는 숫자 표현의 기술적 방어값으로만 남긴다. 확인된 미출전은 −1.5%이며 점수를 부여하지 않는다. 기준 8점·60분 이상이라는 예시에서는 12점 +5,000P, 4점 −5,000P다. 24점은 원래 +20,000P이며 직전 가격 10만P에서는 ±10% 제한으로 +10,000P가 된다. 실제 기준은 DB의 고정 표본으로 정하며 8점으로 하드코딩하지 않는다. 같은 활약의 수익이 현재 가격에 비례해 자동으로 커지지 않는다. 기준 8점/12점 활약 20경기에서 10만P→20만P이며 이전 비율 복리식의 약 26.5만P와 다르다. 저가 구간에서는 ±10% 안전 한도가 먼저 적용될 수 있다. 지속적인 좋은 성적의 포인트 상승은 허용하므로 통화량이나 모든 인플레를 완전히 고정하는 정책은 아니다.

AI와 수치 설명에는 실제 포지션 기준·출전 비율·전후 가격을 전달한다. 기본 6점·10점 만점이라는 설명은 제거했다. 기준 미달이나 가격 하락을 긍정적인 말로만 설명하지 않는다. 기존 공유 캐시·중복 생성 방지·로그인·할당량 제한은 유지한다.

본진·서브팀, 커뮤니티 권한·투표·보유 인증, 스쿼드·거래 정원과 수수료, 차트 기간·리그별 일정은 이번 변경에서 유지한다.

## 검증

단위 테스트 281개, 전체 migration과 SQL 검증 36개, 빌드·타입·린트, PC/모바일 리포트 브라우저 검사를 통과했다. SQL 회귀 검사는 포지션 기준 표본에 미래 경기 제외, 21점 보존, 미출전 표시, 10월 15일 가격 시작, 리포트 연결, 증분 수집 해시 일치, 재실행 멱등성과 지갑/거래/원가 무결성을 검증한다.

## DB 용량 작업 — 실제 완료

약 356.4MB에서 291.7MB로 줄였다. 동일 선수·원인·실행자·한국 날짜의 반복 보류 로그 51,422행을 일별 요약으로 바꾸고 발생 횟수·최초/최종 시각을 보존했다. 운영 로그·경기력 결과·계산 이력의 반환 가능한 공간을 회수했다. 원천 경기 통계·확정 거래·지갑·보유 원가는 삭제하지 않았다.

반복 로그의 이후 누적도 막는 trigger/index도 운영 DB에 설치했다. 기존 비공개 재산정 체크포인트를 재사용하며 새 대용량 백업을 DB에 복제하지 않는다.

## 자동 갱신 경로 보완

bulk 재산정뿐 아니라 다음 일반 자동 갱신에서도 최신 경기가 미출전이면 Performance를 공란으로 유지한다. `position-points` 정책이 기존 조건에서 빠져 이전 출전 점수가 다시 표시될 수 있던 경로를 보완했다. 실제 증분 발행을 거치는 SQL 회귀 검사를 추가해 확인했다.

기존 `CLAUDE_HANDOFF_PRICING_PRIMARY_POLLS_2026-11-06.md`의 기본 6점·0~10점 설명은 이 문서로 대체한다. 과거 migration의 중립 계산 함수는 과거 회귀 검사 전용이며 운영에 다시 실행하지 않는다.

## 상승·하락·미출전 표시

헤더는 상승 → 하락 → 미출전 → 가격 적용 순서다. 마지막 가격에 반영된 경기의 실제 상태로 분류하며, 점수 공란이나 −1.5% 수치만 보고 미출전으로 추측하지 않는다. 미출전은 하락 집계·하락 목록·하락 TOP5에서 제외한다. 최저 가격 때문에 가격이 유지된 미출전도 미출전 수에 포함한다. 성적이 반영된 다음 경기에는 최신 이유로 자동 교체한다. 기존 스냅샷에 작은 `last_price_reason` 컬럼만 추가하며 별도 테이블·외부 API 호출·전체 이력 전송은 없다.

## 디자인 인계 시 유지할 내용

헤더의 상승 → 하락 → 미출전 순서와 분류 기준을 유지한다. 작은 화면에서 수치가 겹치지 않도록 줄바꿈·간격은 다듬어도 된다. 미출전은 0점 대신 공란/대시로 표시하고, 점수 차트나 배지에 10점 상한을 가정하지 않는다. 기술적인 산식 버전 이름을 사용자 화면에 다시 노출하지 않는다. 포지션 기준과 실제 전후 가격은 수치 설명·AI 설명에서 같은 값을 사용한다.
