# 보고서 합산 점수 복원과 세부 지표 확장

운영 상태: 코드와 검증은 완료했다. Supabase 스키마 변경 실행 확인이 만료되어 새 산식은 아직 운영에 적용하지 않았다. 아래 단계가 모두 완료되기 전에 배포·재산정 완료로 보고하지 않는다.

## 확정 정책

사용자는 10점 상한과 기본 6점을 거부했다. 원래 보고서의 배점(출전 2/1, 골 GK10/DF6/MF5/FW4, 도움 GK5/DF4/MF3/FW3 등)을 복원한다. 원점수는 항목 합계 그대로 보존하고 상·하한을 두지 않는다. 20~30점 이상과 음수도 가능하다.

추가 승인 배점: 패스 성공 10회당 +0.5, 볼 회수 +0.5, 클리어런스 +0.25, 드리블 성공 +0.5, 슈팅 차단 +0.5, 피파울 +0.25, GK 공중볼 처리·스위퍼 성공 각각 +0.5. 성공 카운터만 사용한다. 전체 경합 수·터치·API 평점을 또 더하지 않는다. 누락/비정상 카운터는 임의로 채우지 않는다.

초기 가격은 기존의 확정된 이전 시즌 포지션별 백분위 50,000~150,000P를 유지한다. 운영 시작은 2026-10-15 00:00 KST다. 이후 종료된 5대 정규 리그 경기만 가격 변동으로 발행한다. 이전 자료는 고정 기준을 만드는 데만 사용한다.

가격 비교 기준은 운영 시작 전에 종료된 유효 출전의 포지션별 합산 점수 평균이다. 신규 지표를 포함한 같은 배점을 사용하고 표본 수를 기록한다. 운영 시작 이후의 경기는 기준에 섞지 않는다. 기준은 한 번 정한 뒤 동결한다.

변동률 = (이번 경기 점수 − 포지션 기준) / max(|포지션 기준|, 1) × 0.10 × min(출전 분 / 60, 1).
경기당 ±10%, 정수 반올림 후 한도 재확인, 전역 10,000~1,000,000P를 적용한다. 확인된 미출전은 −1.5%이며 점수를 부여하지 않는다. 기준 8점·60분 이상이라는 예시에서는 12점 +5%, 4점 −5%, 24점 +10%다. 실제 기준은 DB의 고정 표본으로 정하며 8점으로 하드코딩하지 않는다.

AI와 수치 설명에는 실제 포지션 기준·출전 비율·전후 가격을 전달한다. 기본 6점·10점 만점이라는 설명은 제거했다. 기준 미달이나 가격 하락을 긍정적인 말로만 설명하지 않는다. 기존 공유 캐시·중복 생성 방지·로그인·할당량 제한은 유지한다.

본진·서브팀, 커뮤니티 권한·투표·보유 인증, 스쿼드·거래 정원과 수수료, 차트 기간·리그별 일정은 이번 변경에서 유지한다.

## 검증

단위 테스트 278개, 전체 migration과 SQL 검증 35개, 빌드·타입·린트, PC/모바일 리포트 브라우저 검사를 통과했다. SQL 회귀 검사는 포지션 기준 표본에 미래 경기 제외, 21점 보존, 미출전 표시, 10월 15일 가격 시작, 리포트 연결, 증분 수집 해시 일치, 재실행 멱등성과 지갑/거래/원가 무결성을 검증한다.

## DB 용량 작업 — 실제 완료

약 356.4MB에서 291.7MB로 줄였다. 동일 선수·원인·실행자·한국 날짜의 반복 보류 로그 51,422행을 일별 요약으로 바꾸고 발생 횟수·최초/최종 시각을 보존했다. 운영 로그·경기력 결과·계산 이력의 반환 가능한 공간을 회수했다. 원천 경기 통계·확정 거래·지갑·보유 원가는 삭제하지 않았다.

반복 로그의 이후 누적도 막는 trigger/index는 두 번째 migration에 준비했지만 실행 확인 대기로 아직 설치되지 않았다. 기존 비공개 재산정 체크포인트를 재사용하며 새 대용량 백업을 DB에 복제하지 않는다.

## 남은 운영 적용 순서

1. `additive_report_position_pricing`와 `compact_repeated_calculation_audit` migration을 순서대로 적용한다. 여기서는 산식을 설치하며 점수·가격 재산정을 자동 실행하지 않는다.
2. 새 애플리케이션 코드를 두 저장소에 배포하고 상태를 확인한다. 구형 코드의 산정 식별자는 새 DB 정책에 결과를 발행할 수 없다.
3. 최신 `kickx_valuation_integrity()` 결과를 기대값으로 `kickx_private.apply_additive_assessments(jsonb)`를 한 번 호출한다. 기존 검증된 경기 근거에 새 점수를 계산하고, 기준을 동결한 다음 10월 15일부터 가격 경로를 재생성한다. 이 함수는 비공개·관리 작업 전용이다.
4. 가격 방향/±10%/점수 합계/리포트 해시/서비스 시작 경계 및 재실행을 검증한다. 지갑·체결 거래·보유 원가 해시가 같아야 한다.
5. 실제 처리 건수와 고정 포지션 기준을 증빙 JSON에 반영한다. 그 전에는 운영 완료로 표현하지 않는다.

기존 `CLAUDE_HANDOFF_PRICING_PRIMARY_POLLS_2026-11-06.md`의 기본 6점·0~10점 설명은 이 문서로 대체한다. 과거 migration의 중립 계산 함수는 과거 회귀 검사 전용이며 운영에 다시 실행하지 않는다.
