## 2 서버·DB 변경 (적용 필요)

- `supabase/migrations/20261103160000_profile_avatar.sql`: `profiles.avatar` 열(`icon:*` 또는 `club:<teamId>` 형식 검사), 응원 구단에서 빠진 엠블럼은 자동 초기화 트리거, 회원 본인 insert/update 권한.
- **운영 DB에 아직 적용하지 않았다.** 적용 전에도 사이트는 정상 동작한다: 프로필 읽기는 `avatar` 열이 없으면 기존 열만 다시 읽고, 저장은 아이콘을 고르지 않았으면 기존대로 저장한다. 아이콘을 골라 저장하면 적용 전까지 `프로필 아이콘 저장을 준비 중입니다` 안내(503)가 나온다.
- `app/api/kickx/profile/route.ts`, `server/kickx/supabase-repository.ts`: 위 동작. `lib/kickx/validation.ts`: `parseAvatar`, `parseProfile`의 `avatar`(응원 구단 엠블럼만 허용, 생략 시 기존 값 유지).
- 다른 회원의 선택 아이콘을 커뮤니티·랭킹에 보여주려면 `kickx_posts`/`kickx_post`(댓글 포함)와 랭킹 응답에 작성자 `avatar`를 추가해야 한다. 이번에는 SQL 함수를 바꾸지 않았고, 다른 회원은 ID 기반 고정 아이콘으로 보인다(본인 글은 본인 선택이 보임).
