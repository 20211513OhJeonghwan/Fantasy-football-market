## 1 포메이션 변경 모달 (`formation-change.tsx`, `formations.css`)

| 항목 | 반영 |
| --- | --- |
| 비교 | 맨 위에 `현재 → 새 포메이션`을 두고, 각 포메이션을 작은 도형(줄별 점)으로 미리 보여 준다. 새 포메이션은 수비 3·4·5줄 묶음 선택 상자로 고른다 |
| 초과 인원 | 포지션별 칩에 `선택한 수 / 필요한 수` 또는 `유지`를 표시한다. 다 고르면 완료 색으로 바뀐다 |
| 진행 | `벤치로 이동할 선수 x / y명 선택` 진행 막대(role=status) |
| 행 상태 | 체크박스와 글자로 구분한다: `선택 시 벤치로 이동` / `선택됨 · 벤치로 이동` / `선택 완료 · 다른 선수를 해제하면 선택 가능` / `경기 거래 제한 · 선택 불가`. 체크박스 18×18과 키보드 포커스 링은 그대로 두었다 |
| 규칙 | 행마다 반복되던 경고를 없애고 규칙 상자 하나로 합쳤다. 상자는 오류 색이 아닌 중립 색이다 |
| 버튼 | 확정·취소 영역을 모달 아래쪽에 고정(sticky)했다. 버튼 문구는 `n명 벤치 이동 후 변경` 또는 `포메이션 변경 확정` |

## 2 벤치 목록 (`squad.tsx`, `squad-market.css`, `bench-deadline.tsx`)

- 행 순서: 선수(사진·이름·포지션) → 이동 사유 → `매각 기준가 P` → 기한(`자동 매각까지 …` + 실제 만료 시각) → `매각` 버튼. 기한이 지나면 버튼 대신 `자동 매각 처리 중` 표시가 나온다.
- 목록 위에 표준 문장을 둔 규칙 상자를 넣었다. 벤치를 오류처럼 보이게 하는 빨간 배경은 쓰지 않았다.
- 기한 강조(서버가 준 만료 시각으로만 계산): 24시간 미만은 주황, 1시간 미만과 만료는 하락 색 알약.
- 모바일: 한 열로 바꾸고 선수 → 기준가·기한 → 전체 너비 버튼 순서로 배치했다.

## 3 경기장·미니 시장

- 배치 모드:
  - `1단계/2단계/저장 중` 단계 배지를 붙였다.
  - 선택한 선수는 노란색, 옮길 수 있는 같은 포지션 자리는 점선 테두리(동작 줄이기 설정을 켜면 깜박임 없음)로 표시하고, 나머지 자리는 흐리게 한다.
- 미니 시장 벤치 행: 가격 앞에 `매각 기준가` 라벨을 붙이고, 공개 가격 변동은 표시하지 않는다.
- 매각 모달: 기존 `매각 기준가` + 기한 표시, 저장 중·견적 만료·실패 상태를 그대로 유지했다.
