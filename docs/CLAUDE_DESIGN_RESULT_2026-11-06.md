# KICK-X 클로드 디자인 결과 (2026-11-06)

기준: `main` `1560a2d`(PR #37 자동 스쿼드·시장·커뮤니티 병합본)과 `CLAUDE_HANDOFF_SQUAD_MARKET_COMMUNITY_2026-11-05`. 서버·SQL·정원/가격 정책·거래 흐름은 바꾸지 않았다. 13번 포지션 변경 정책은 정책 결정 전이라 화면에도 반영하지 않았다.

## 1 바뀐 화면

| 영역 | 변경 |
| --- | --- |
| 스쿼드 경기장 | 빈자리는 점선 유니폼 + `FW 매입` 같은 점선 라벨, 선택한 빈자리는 노란 점선. 선택한 보유 선수 자리에는 `매각` 표시가 붙는다 |
| 스쿼드 시장 | 안내 문구와 선택 상태를 한 카드로 통합: 빈자리 선택은 노란 점선 카드(`빈자리 · 아래에서 선수 매입`, 포지션 정원), 보유 선수 선택은 검정 왼쪽선 카드 + 매각 버튼. 포지션 칩은 정원이 차면 회색 + `마감`. 목록의 보유 선수는 `보유` 배지와 옅은 배경. 기존 초과 보유 경고는 빨간 안내 상자로 칩 위에 표시 |
| 거래 모달 | 포지션별 칸에 상태 문구(`이번 매입`·`이번 매각`·`정원 마감`·`n자리`), 이번 선수 포지션은 노란 배경 + 검정 테두리, 매입이 막히면 그 칸만 빨강. 막힌 경우 해제 방법 안내. 총원 `n / 11명` 유지 |
| 글쓰기 대상 | 고정 대상 카드: 선수 사진·`게시 대상`·`○○ 커뮤니티`·`고정` 배지. 대상 없음은 점선 + 시장 링크 |
| 거래 첨부 | 전체·빠른 글쓰기 모두 첨부 미리보기 카드 안에 `첨부 취소` 버튼(드롭다운 빈 옵션에 의존하지 않음) |
| 빠른 글쓰기 | `제목 *` 라벨이 한 줄로 보이도록 정리 |
| 구단 게시판 | 작성자 칸 폭 확대(닉네임 잘림 감소). 구단 선택은 검색 왼쪽 유지 |
