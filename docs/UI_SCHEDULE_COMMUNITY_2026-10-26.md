# 일정과 커뮤니티 변경 — 2026-10-26

## 경기 일정

- 전체 일정은 활성 가격 정책에 관계없이 5대 정규 리그만 표시한다. 연도 선택, 1~12월 선택, 이전·다음 월, 최신 버튼을 제공한다.
- KST 월 경계로 한 달만 조회한다. 정규 리그 월 조회는 최대 500건으로 제한하고 공유 서버 캐시·클라이언트 요청 캐시를 사용한다. 전체 시즌을 브라우저로 내려보내지 않는다.
- 페이지 진입과 최신 버튼은 오늘 날짜로 이동한다. 오늘 경기가 없어도 오늘 위치를 표시한다. 다른 달을 고르면 그 달의 일정으로 바뀐다.
- 구단 상세는 별도의 `club_fixture_catalog` 보안 호출자 뷰로 모든 대회를 조회한다. 컵 대회명을 표시하는 작은 대회 사전도 유지한다.
- report-v3 전환 뒤에도 기존 유지관리 작업에서 컵·유럽 대회의 일정만 수집한다. 그 경기를 새 점수·가격 계산에 넣거나 선수별 통계·프로필 호출을 추가하지 않는다. 기존 API 예약 한도를 공유한다.
- 실제 표시 범위는 BSD가 제공하고 수집한 일정에 한정된다. 미발표 대진을 생성하지 않는다.

## 커뮤니티

- 상단 메뉴의 선수 커뮤니티와 구단·선수 전환 스위치를 제거한다. `/community`는 구단 게시판이며, 이전 `/community/players` 진입은 선수 탐색으로 연결한다.
- 선수 상세의 커뮤니티 탭과 개별 선수 커뮤니티 주소는 유지한다. 선수에 고정된 빠른 글쓰기도 유지한다.
- 인기 게시글, 구단 라운지 찾기, 구단 빠른 글쓰기 안내를 제거했다. 구단 게시판에는 응원 구단 바로가기, 구단 선택, 검색, 글쓰기와 목록이 있다.
- 목록은 번호·제목·작성자·작성일·조회·추천 순이다. 댓글 수와 거래 첨부 표시를 제공하며, 상세에서 댓글·공감·신고·수정·삭제를 처리한다. 모바일은 제목 아래 작성 정보를 표시한다.
- 응원 구단은 리그별 1개, 최대 5개다. API와 DB 트리거에서 중복 리그·범위 밖 구단·누락 구단·다른 회원 수정을 차단한다. 선택한 모든 구단에 글·댓글을 쓸 수 있고, 읽기는 기존대로 공개다.
- 기존 선택은 `profiles.team_ids`로 보존한다. `team_id`는 기존 배지·랭킹 기록의 호환 필드이며, 전체 응원 구단 권한은 배열을 사용한다. 랭킹의 자산·수익률 산식은 유지한다.

## 홈과 AI

- 홈 선수 목록은 페이지당 10명, 번호·이전·다음 페이지로 바뀌었다. 검색·필터 변경 시 1페이지로 돌아간다.
- AI 설명은 한국어 문장 단위로 나누어 표시한다. 소수점 수치를 분리하지 않으며, 기존 캐시 문구도 적용된다. 재생성·추가 모델 호출·DB 문구 재저장을 하지 않는다.

## Claude 인계

- Yellow Playbook과 기존 polish를 유지한다. 이번 전용 스타일은 마지막에 읽는 `calendar-board.css`에 있다.
- 전체 일정과 구단 일정의 대회 범위를 합치지 않는다. 구단 일정의 컵 노출과 가격 평가의 컵 제외는 함께 유지한다.
- 구단/선수 허브 스위치, 인기글, 라운지 탐색 그리드와 구단 빠른 작성 안내를 복구하지 않는다.
- 응원 구단 권한에 `profile.team` 단일 비교를 쓰지 않는다. `supportedTeams`/`supportsTeam`과 서버 판정을 사용한다.
- 가격 정책, 거래·인증, 4-3-3, 같은 선수 중복 금지, AI 캐시는 이번 작업에서 유지한다.

- 운영 브라우저에서도 12개월 선택, 168경기와 오늘 위치 노출을 확인했다. 구단 커뮤니티의 전환 스위치·인기글·라운지 탐색·빠른 작성 영역은 모두 제거됐다.
- 이 UI와 응원 구단 변경은 이전 시즌 기준 수집·새 가격 정책 활성화와 별개로 바로 적용됐다.
