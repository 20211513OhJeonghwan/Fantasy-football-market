# 공식 클럽 경기 범위 확대와 지속 갱신

## 적용 범위

선수 시장은 현재 유럽 5대 리그 소속 선수로 유지한다. 추가 대회에서는 이 구단들이 참가한 경기만 수집하며, 상대 구단이 다른 리그나 하부 리그에 소속돼도 일정·결과와 전체 원본 경기 통계는 보존한다. 컵 참가를 현재 소속 리그로 사용하지 않는다. 상대 선수의 기록을 보존하는 것과 그 선수를 시장에 등록하는 것은 별개다. 보유 선수의 기록·가격은 소속 변경 이후에도 보존한다.

BSD `/leagues/`에서 이름을 정확히 대조해 ID를 확인한다. 챔피언스리그·유로파리그·컨퍼런스리그·UEFA 슈퍼컵, FA컵·카라바오컵·코파 델 레이·코파 이탈리아·DFB 포칼·쿠프 드 프랑스가 현재 제공 대상으로 확인됐다. 국가별 슈퍼컵, FIFA 클럽월드컵·인터컨티넨털컵도 탐색 목록에 넣었으며, 제공자 목록에 실제로 등장하면 자동으로 대상으로 추가한다. 미제공 대회를지원한다고 표시하거나 추정 ID로 호출하지 않는다. 여자·유소년·국가대표·친선경기는 이번 범위에 포함하지 않는다.

## 수집과 갱신

- 정규 5개 리그의 기존 일일 구단·선수단 갱신과 15분 간격으로 설정된 종료 경기 확인을 유지한다. GitHub Actions 실행 지연이 있을 수 있으므로 15분 SLA를 뜻하지 않는다.
- 추가 대회는 현재 시즌을 자동 확인하고 첫 수집 시 시즌 시작부터 현재+21일까지 30일 이하 구간으로 나눈다. 예선·본선·토너먼트 단계는 조회에서 제외하지 않는다. 새로 확정된 경기 일정은 이후 일일 조회로 추가한다.
- 컵 전용 큐는 날짜가 바뀌거나 실행이 중단돼도 미완료 단계와 원본 응답을 보존한다. 자료 저장과 다음 단계·자식 작업 저장은 한 DB 트랜잭션이다. 실패 작업은 15분 뒤 재시도하며, 다른 대회의 진행을 막지 않는다.
- 최초 수집 완료 표시는 해당 대회의 모든 작업이 끝난 뒤에만 저장한다. 이후에는 최근 7일과 향후 21일의 일정·정정을 확인한다. 오래된 컵 경기도 재확인 대상에 남긴다.
- 정규 리그의 7일보다 오래된 경기 중 재확인 시각이 지난 최대 4개를 매 실행에서 순환 재조회한다. 컵은 최대 3개다. 한 실행의 시간·API 예산 안에서 처리하고 다음 실행으로 이어간다. 대회 탐색은 하루 한 번 캐시하며, BSD 잔여 호출이 1,500회 미만이면 과거 정정과 컵 백필을 미루고 신규 정규 리그 경기 확인에 예산을 남긴다. 정상 기록을 확보한 정규 경기의 첫 6시간 정정 재조회는 1시간 간격, 이후는 6시간 간격이고 빈/미제공 기록은 15분 간격이다.
- 미제공/빈 선수 통계는 경기 일정과 결과를 저장하면서 경고를 남긴다. 이전에 확보한 정상 선수 기록을 빈 응답으로 삭제하지 않는다.
- 동일 구단·선수 ID는 갱신하고, 선수+경기 ID는 upsert한다. 경기 중복으로 점수나 가격 변동을 다시 누적하지 않는다. 현재 선수단 전체를 검증한 뒤에만 이적·등록 변화로 소속을 수정한다. 한글 표시명·별칭은 기존 컬럼/테이블에 보존된다.

## 연장전·승부차기

BSD의 `finished`만 보고 일반 종료로 단정하지 않는다. `extra_time_score`와 `penalty_shootout`을 확인해 AET/PEN으로 정규화한다. 정규시간 스코어에 연장 득점을 합치고 승부차기 스코어는 별도로 보존·표시한다.

점수 계수와 가격 산식은 form-v2를 유지하고 계산 입력/불변 revision에 `scoringRevision: club-competitions-v1`을 기록한다. 활성화 전에는 기존 90분 처리로 계산한다.

- 실제 출전은 경기 길이에 따라 최대 90분 또는 120분. 연장전 득점·도움·수비 기록도 합산한다.
- 출전 기본점은 `10 + 20 × min(출전분,90)/90`, 최대 30점이다.
- 무실점과 팀 승리 보너스의 비율은 `출전분/경기 길이`. 120분 풀타임 DF 무실점은 20점이며, 연장전에만 30분 출전한 DF는 5점이다.
- 승부차기 득점은 개인 골·출전 중 실점·무실점 판정에서 제외한다. 승부차기 승리팀은 팀 승리 보너스를 받는다.
- 승부차기 경기에서 기존 v1 페널티 선방 카운터가 경기 중 선방인지 승부차기 선방인지 확정할 수 없으므로 해당 추가 보너스는 제외하고 경고한다.
- ET/PEN 결과나 출전 구간을 검증할 수 없으면 보류한다. 계산 가능한 컵 출전은 정규 리그와 함께 최근 5유효출전에 들어간다. 신규 컵 기록이 부족하면 해당 경기만 대기하고 기존 리그 가격은 계속 계산한다. 이미 가격에 반영한 경기 기록이 불완전해지면 기존 가격을 보존하고 거래를 대기시킨다.
- 최근 5출전 가중치 5:4:3:2:1, 목표가 점수당 2,000P, 차이의 40% 조정, 출전분에 따른 경기당 최대 ±8% 등은 그대로다. 연장전도 별도의 두 경기가 아닌 한 경기다.

현재 시즌의 과거 컵 경기가 새로 확보되면 고정 기준 시각 이전의 초기값 표본 또는 그 이후의 가격 변동에 반영될 수 있다. 지갑·보유 원가·완료 거래를 초기화하지 않는다. 여러 과거 경기를 한 번에 반영한 발행 가격의 변화는 개별 경기 상한보다 클 수 있다.

## 화면과 운영 활성화

경기 대회 필터에는 컵·유럽 대항전을 포함하고 대회 단계, 별도 승부차기 스코어, 기록/계산 대기·보류·일부 반영·점수 계산 완료를 표시한다. 선수/팬 구단 선택은 정규 5대 리그 기준이다.

`supabase/migrations/202610140001_club_competitions.sql` 전체를 **기존 v2 SQL 이후 한 번** 실행해야 한다. SQL은 기존 자료를 보존하고 새 큐와 상태 필드를 생성하며 `club_competitions_enabled=true`로 활성화한다. 기존 초기가격 기준 시각은 바꾸지 않는다. 적용 전에도 배포된 앱은 기존 정책으로 동작한다. 적용 후 자동 작업이 현재 시즌의 지난 컵 경기를 순차 수집한다. 별도 초기 데이터 전체 삭제나 재가입은 필요 없다.

실제 제공 범위와 점수 계산 여부는 `Competition coverage read-only audit` workflow의 결과로 검증한다. 이 검증은 운영 DB에 쓰지 않는다.
