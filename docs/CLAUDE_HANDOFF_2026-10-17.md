# Claude 디자인 인계 — 2026-10-17

이번 변경의 기능과 운영 설명은 `docs/REQUIREMENTS_UPDATE_2026-10-17.md`가 기준이다.

- 선수 등번호가 모든 화면과 모델에서 제거됐다. 구단 명단 카드는 사진/이름/가격의 3열이다. 카드·상세·유니폼에 번호를 재도입하지 않는다.
- 게시글 카테고리/주제 선택, 카테고리 탭·배지는 없다. 선수/구단 커뮤니티 구분과 대상 선택은 그대로 필요하다. 기존 글과 글쓰기·수정·빠른 글쓰기·검색·공감순/최신순을 유지한다.
- `TradeButton`은 `player.tradeWindow.locked`이면 `경기 거래 제한`을 표시한다. DB가 견적과 체결을 검사한다. 디자인에서 클라이언트 계산으로 이를 우회하거나 제한된 버튼을 활성화하지 않는다. 종료 미확인 시 임의 해제 시각을 보여주지 않는다. `unlockAt`이 있으면 정확한 재개 예정 시각을 보조 표시할 수 있다.
- 상단 바의 `경기 확인`과 `가격 적용`은 서로 다른 시각이다. 가격이 변하지 않았을 때 확인 시간을 가격 적용 시간으로 복사하지 않는다.
- 보이는 탭에서 공통 데이터/선수·경기 목록/선수 상세는 30초마다 다시 조회한다. 자동 조회 때 로딩 화면으로 바꾸지 않으며 작성 중인 글과 선택한 검색 조건을 초기화하지 않는다.
- 기존 a7142bf 이후 커뮤니티 스타일을 유지했다. 스타일 수정은 `app/styles/pages.css`, `community.css`, `components.css` 및 해당 컴포넌트에서 이어갈 수 있다.

주요 파일: `components/kickx/{players,player-card,team,squad,ui,community,community-feed,community-detail,shell,provider,catalog}.tsx`, `lib/kickx/types.ts`.

운영 SQL과 Supabase Cron 활성화는 위 기능 문서의 순서를 따른다. 화면에 `거래 규칙 적용 중`이면 이를 가리는 대신 DB 설치 여부를 먼저 확인한다.
